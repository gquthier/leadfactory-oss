# Banque de concepts natifs (client-agnostique)

Chaque concept est un gabarit de prompt paramétrable. Choisir 8 à 12 concepts distincts par pack.

| Concept | Description | Texte porté |
|---|---|---|
| Notes iOS | capture d'une app de notes, liste ou pensée du fondateur | hook + 3 puces |
| Advertorial | bloc éditorial façon article de presse, titre + chapô | titre + sous-titre |
| Conversation iMessage | échange de 3 à 4 bulles entre prospect et fournisseur | douleur → réponse |
| Tweet / post | carte de post social avec avatar et texte | hook en une phrase |
| Selfie UGC | portrait brut au téléphone, texte en surimpression | hook court |
| Portrait autorité | fondateur en situation, lumière naturelle, citation | citation + nom |
| POV | point de vue à la première personne (écran, bureau, chantier) | légende |
| Listicle | « 3 erreurs… », colonne numérotée | 3 items |
| Mockup produit | l'offre ou le livrable montré comme objet (dashboard, document) | titre + CTA |
| Témoignage | carte avis avec étoiles, verbatim client autorisé | verbatim + prénom |
| Infographie | 3 blocs chiffrés reliés | 3 chiffres sourcés |
| Dataviz | courbe ou barres avant/après | légende + source |
| Post natif | visuel qui ressemble à un post organique de la marque | phrase + logo discret |
| Pattern interrupt | image inattendue mais liée, texte contrasté | hook contre-intuitif |

Directives communes : composition bord à bord, aucune marge blanche réservée ; logo en surimpression discrète ; CTA en majuscules aligné sous le headline dans la même colonne ; texte français court et net ; référence de style concurrente = style seulement, jamais son copy.
