# Gabarit de prompt d'art-direction (7 blocs)

```
1. Rôle et format : "Ad creative for Meta, {ratio} ({pixels}), edge-to-edge composition, image fills the full frame, NO white margins, NO white header or footer bar."
2. Style : "{style : photo documentaire | typographie éditoriale | dataviz | citation | infographie | split | mockup} in the spirit of {concept natif}."
3. Marque : "Palette {hex primaire}, {hex secondaire}, accent {hex} used only for the CTA. Fonts feel: {famille}. Logo overlay top-left, subtle. Tone: {ton}. Avoid: {dont}."
4. Scène : "{description de la scène / sujet / ambiance / lumière}, {référence de style si fournie : 'style reference only, do not reuse its text'}."
5. Texte exact à incruster : "Headline: «{hook}». Subline: «{sub}». CTA button label in ALL CAPS: «{CTA}». Place the CTA directly below headline and subline, same vertical column, same alignment. French text, spelled exactly as given, sharp and legible."
6. Hiérarchie : "Headline dominant (≈ {x}% of width), subline secondary, CTA pill high contrast, keep bottom {14}% safe for platform UI."
7. Qualité : "Photorealistic (or: clean vector), no distorted hands, no extra letters, no lorem ipsum, no watermark, sRGB."
```

Checklist du prompt : palette exacte présente · texte exact entre guillemets · format et zones sûres · une seule variable de test différente de la cellule voisine · références de marque jointes si elles existent · interdits de marque listés.
