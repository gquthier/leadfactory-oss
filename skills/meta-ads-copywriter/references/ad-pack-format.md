# Format du pack `ads-multi-variantes.md`

```markdown
# Pack Meta Ads — {client}
Offre : … · Mécanisme : … · CTA cible : … · Audit offre : {score}/20 ({verdict})

## Avatar (5 lignes)
## Angles testés
1. {Angle} — pourquoi (1 ligne)
2. …
3. …

## 30 secondes
#### 1A — 30 secondes · {N} mots — {Angle}
**Hook (0–3 s)**
Texte exact prononcé. 1 à 2 phrases.

**Body**
Texte exact. Phrases courtes. Douleur reformulée, preuve ou mécanisme, bénéfice clé.

**CTA**
Une action, une raison d'agir maintenant.

*Indication scénique (seulement si indispensable)*

**Copies Meta associées**
- **Primary text ≤ 125 c** : hook + bénéfice + CTA
- **Primary text 125–200 c** : accroche locale ou ciblée + preuve + CTA
- **Primary text 200–280 c** : angle Quoi/Qui/Quand + CTA + raison maintenant
- **Headline ≤ 40 c** : « {Résultat} en {délai} sans {sacrifice} » ou « Cas client : {chiffre} à {lieu} »
- **Description ≤ 30 c** : rareté ou échéance réelle

#### 1B — 30 secondes · {N} mots — {Angle}
…

## 60 secondes
…
## 90 secondes
…

## Réserves
Preuves à fournir, claims à vérifier, points de conformité à contrôler par l'utilisateur.
```

## Comptages

Mots par script au débit de référence de 155 mots par minute, silences compris : 78 (30 s), 156 (60 s), 233 (90 s). Fourchettes hautes tolérées : 70–90 / 150–180 / 220–250. Afficher le compte dans le titre.

Caractères par copie : vérifier par comptage réel (une headline française dépasse 40 caractères sans prévenir), pas à l'œil.

## Interdits

JSON, tableaux d'horodatage, colonnes VO / à l'écran, copier-coller entre variantes, plus de 3 indications scéniques dans le pack.
