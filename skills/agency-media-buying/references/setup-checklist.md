# Fiche de configuration et preuve

| Bloc | À renseigner depuis le compte/brief | Preuve de fin |
|---|---|---|
| Identité | client, ad account, Page/profil, propriétaire | Lecture des IDs autorisés |
| Mandat | création/activation autorisées, limites, dates | Instruction ou mandat existant |
| Objectif | résultat business, objectif plateforme, événement | Compatibilité confirmée dans la version utilisée |
| Audience | géographie, contraintes, exclusions | Lecture de ciblage enregistré |
| Budget | montant, devise, unité API, niveau campagne/ad set | Valeur relue et conversion d’unité vérifiée |
| Destination | URL finale/formulaire, mobile, mentions, CRM | Parcours réel ou limite identifiée |
| Créatives | concepts, format/placement, version, droits, CTA | Preview et IDs média réels |
| Mesure | pixel/dataset si utilisé, événements, attribution, UTM | Événement test explicitement distingué d’un résultat réel |
| Diffusion | pause/activation, fuseau, début/fin | Statut configuré et statut effectif relus |
| Reprise | IDs, journal, action incertaine | Recherche des objets existants avant retry |

Documentation à vérifier lors de l’exécution : [Meta Marketing API](https://developers.facebook.com/docs/marketing-api/). Lecture web du parcours de création tentée le 1er octobre 2026 : réponse 429 ; aucun schéma actuel certifié par cette tentative. Les champs historiques fournis ailleurs dans le pack sont des pistes à revalider, pas un contrat actuel garanti.

Une absence de conversion peut venir d’un défaut de mesure ou d’un petit échantillon. Présenter dépense, impressions, clics lien, conversions et leads qualifiés séparément, avec dates/devise/fenêtre et source. Reporter un ratio comme inconnu si son dénominateur manque ou vaut zéro.
