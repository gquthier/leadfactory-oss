# Structures de script

## Mode coach-dtc — 16 blocs, 8 à 12 min (1200 à 1800 mots)

Format de chaque bloc :

```
[MM:SS–MM:SS] [VISUEL : …]
Texte de voix off, écrit pour l'oreille.
```

| # | Bloc | Contenu |
|---|---|---|
| 1 | 0:00–0:15 Hook | interruption + promesse ; chiffre choc, affirmation contre-intuitive, ou « si tu es [X], dans les [Y] prochaines minutes tu vas découvrir… » |
| 2 | 0:15–0:45 Pour qui / pas pour qui | filtre polarisant |
| 3 | 0:45–1:30 Qui je suis + autorité | nom, rôle, 3 preuves concrètes |
| 4 | 1:30–2:30 Point de départ | contexte frustrant, verbatim de douleur |
| 5 | 2:30–3:15 Déclic | le moment où tout devait changer, pic émotionnel |
| 6 | 3:15–4:15 Tentatives logiques | solutions déjà essayées et pourquoi elles échouent (neutralise les concurrents) |
| 7 | 4:15–5:00 Le vrai problème | recadrage, ennemi commun |
| 8 | 5:00–5:45 Le mur | douleur maximale : coût de l'inaction, comparaison aux pairs, regret futur, érosion identitaire |
| 9 | 5:45–6:30 Grande prise de conscience | l'insight qui prépare le mécanisme |
| 10 | 6:30–7:30 Solution + nom de la méthode | mécanisme révélé, 3 raisons pour lesquelles il marche |
| 11 | 7:30–8:30 Nouvelle vie | dream outcome tangible, détails sensoriels |
| 12 | 8:30–9:15 Preuves | 3 preuves concrètes minimum, nommées et sourcées |
| 13 | 9:15–10:00 Bénéfices de la méthode | 4 bénéfices lus lentement |
| 14 | 10:00–10:45 Offre | 4 leviers de valeur, stack complet, ancrage prix |
| 15 | 10:45–11:30 Objections + filet de sécurité | top 3 objections, garantie |
| 16 | 11:30–12:00 CTA | une action, répétée, rareté réelle si elle existe |

## Mode b2b-specialist — 8 blocs, 3 à 5 min (450 à 750 mots)

Hook → Problème → Agitation → Solution → Bénéfices → Preuves → Offre et urgence douce → CTA.

Règles : ton consultatif et sobre, « vous », preuves avant promesses, vocabulaire métier, aucune hyperbole. Angle dominant à choisir : statistique de douleur / mécanisme / cas client / ROI / conformité. Urgence douce uniquement (créneaux limités, audit offert). Données manquantes → hypothèses réalistes en italique, étiquetées « estimation ».

Rendu :

```
_Hook_
VO : …
Onscreen : "…"

_Problème_
VO : …
Onscreen : "…"
```

Slides de 5 à 12 secondes. Pas de numérotation, pas de JSON, pas de banque de hooks ni de plan de test dans ce livrable.
