# Frameworks

| Framework | Structure | Quand |
|---|---|---|
| PAS | problème → agitation (coût, conséquence) → solution en une phrase → CTA | douleur saillante et connue |
| AIDA | attention (fait précis) → intérêt (mécanisme) → désir (preuve) → action | cible endormie sur le sujet |
| BAB | avant (situation) → après (résultat concret) → pont (comment) | transformation claire et prouvable |
| 4U | utile, urgent, unique, ultra-spécifique | urgence réelle (échéance, fenêtre) |
| SLAP | stopper (chiffre), regarder (calcul), agir (CTA), acheter (prochaine étape) | ROI démontrable |

Gabarit PAS :

```
Objet : {douleur en 3 à 5 mots}

Bonjour {{firstName}},
{observation factuelle sur {{companyName}} ou son secteur}.
{problème dans ses mots}. {conséquence concrète}.
On {mécanisme en une phrase} pour {ICP} ; {preuve courte si vraie}.
{question simple} ?
{prénom}
```

Rythme d'une séquence de 4 : porte ouverte → preuve → autre angle ou ressource → clôture douce.
