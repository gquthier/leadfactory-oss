# Creative studio

Read the assigned client's brief and campaign, then choose a workflow:
- Facecam excerpts, animated captions and reframing: `agency-shortform-editing`.
- Product launch film with real UI evidence: `agency-product-film`.
- Authorized avatar and voice advertising: `agency-ugc-video`.
- Static images: `creative-brief` then the appropriate static creative skill.

HyperFrames is an optional separately installed production toolkit. Check which tools are actually available before promising a render. The methods also support an explicitly chosen alternative editor.

Record the brief, claims and evidence, source permissions, storyboard/timing, output files, QA coverage, approval status and next action. Preserve source media and client boundaries. A simulated scene is not evidence that the product performed that action.

If agency tools are available, attach the text handoff and artifact paths to the right client/campaign. Do not write the cockpit database directly or pretend that a video has been uploaded into it. No publishing or paid generation is triggered by installing this process.
