# Passage de relais

Structure d'un relais, à écrire dans un vrai message ou une vraie tâche :

- Étape (`stage`) et produit concernés :
- De / vers :
- Objectif :
- Entrées et sources datées :
- Périmètre autorisé :
- Livrable attendu et critère d'acceptation :
- Échéance ou priorité :
- Livrable produit et sa vérification :
- Information manquante / prochaine action :

Le destinataire vérifie le périmètre et les entrées, produit le livrable, puis répond avec son
emplacement et sa vérification.

Si aucun outil de message entre agents n'existe dans l'exécution en cours, enregistrer le
relais comme **en attente** et nommer qui doit le remettre. Ne jamais raconter comme exécuté
un échange qui n'a été qu'écrit dans un fichier.
